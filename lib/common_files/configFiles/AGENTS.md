## Conventions

- Handlers are class members written as arrow functions (they keep `this` when passed to a router).
#{{!rxjs}} - Express 5 forwards rejected promises to the error handler: throw `createHttpError.NotFound()` and friends, no try/catch needed.
#{{rxjs}} - Controllers use rxjs: end a pipeline with `.subscribe({ next, error: next })` so errors reach the error handler.
- Never return a password hash; never log secrets. Configuration comes from environment variables read in `src/config/env.ts` (import `env`, never `process.env`): document a new one in `.env.example` and the README.
#{{mongo}} - `MONGO_DB` is the MongoDB connection string.
#{{postgres}} - `DATABASE_URL` is the PostgreSQL connection string.
#{{auth}} - `SECRET_KEY` signs the JWTs; it is generated into `.env` and must be a long random value in production.
- Use the `logger` (`src/config/logger.config.ts`), not `console.log`.
- List endpoints return `{ data, meta }` through `parsePaging` / `pageOf`.
#{{zod}} - Validate every request body with `validate(schema)` in the route file; add the schema under `src/validation/`.
#{{auth}} - Protected routes go behind `requireAuth`; keep `/auth`, `/health` and `/ready` public. Routes on a user's own record add `requireSelf`.
#{{refresh}} - Only a hash of a refresh token is stored; never log or return one except in the login and refresh responses. `ACCESS_TOKEN_TTL` and `REFRESH_TOKEN_TTL_DAYS` set the lifetimes.
#{{roles}} - Admin-only actions add `requireRole('admin')` after `requireAuth`. Never let a request body set `role`: it is deliberately not in the `pick` whitelist.

## Adding a resource

1. Add `src/controllers/<name>.controller.ts` and `src/routes/<name>.route.ts`, copying the user ones.
2. Mount it in `src/routes/index.ts`.
#{{mongo}} 3. Add a model under `src/models/`.
#{{postgres}} 3. Add the model to `prisma/schema.prisma`, then `npm run db:migrate`.
#{{zod}} 4. Add its schemas under `src/validation/` and use `validate(...)` on the routes.
#{{openapi}} 5. Add its paths to `src/openapi.ts`.
#{{test}} 6. Add a test under `test/`.
